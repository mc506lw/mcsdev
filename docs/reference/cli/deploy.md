# `mcsdev deploy`

按 `mcsdev.yml` 部署一次，然后按 `restart` 策略重启。不监视文件变化。

```
mcsdev deploy [options] [ids...]
```

## 参数

| 参数 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `[ids...]` | 位置参数 | 全部条目 | 只部署指定 id（`mcsdev config` 里能看到 id） |
| `--force` | 开关 | 关 | 忽略「已是最新」，强制重新复制 |
| `--dry-run` | 开关 | 关 | 只打印将做什么，不改文件、不重启 |
| `--no-restart` | 开关 | 关 | 只拷文件，不重启 |

## 执行流程

1. 向上找 `mcsdev.yml`（最多 8 层）并解析；
2. 打印目标（配置路径 + `plugins/` 路径）；在子目录运行时额外警告；
3. **全局错误**（yml 级）→ 打印并退出 1；
4. **点名校验**：`ids` 里有未知 id → 打印可选列表并退出 1；
5. **条目级错误**：只检查被点名的条目（不点名则检查全部）；
6. 逐条部署：
   - 内容相同（大小 + sha256）且没 `--force` → `已是最新`，跳过；
   - 有变化 → **先复制**（原子替换：临时文件 + rename），**再删**同前缀旧版本；
   - 每条只要没失败（含「已是最新」）就记进 `<plugins>/.mcsdev-manifest.json`；
7. 打印汇总行；
8. 有部署动作 → 按 `restart.type` 重启并探测端口；没有部署动作 → 跳过重启。

## 输出

```
  配置  E:\dev\pylon\mcsdev.yml
  目标  E:\Minecraft\开发\Pylon开发\plugins
✔ pipez: 部署 Lapis-Pipez-0.1.59.jar + 清理 1 个旧版
· cable: 已是最新
✔ sidedio: 部署 SidedIO-2.0.0.jar
  ── 2 部署 · 1 已是最新 · 0 失败
→ 执行重启命令：./restart-dev-server.sh
✔ 重启命令执行完成
✔ 服务器已就绪（端口 25565 可连，等待 8s）
```

三种前缀：`✔` 成功、`·` 跳过、`✖` 失败。

## `--dry-run` 的承诺

**不改动任何文件**，包括：

- 不复制、不删除、不写清单；
- **不创建 `plugins/` 目录**（建目录也算写盘）；
- 不重启。

输出形如：

```
✔ pipez: [dry-run] 复制 Lapis-Pipez-0.1.59.jar + 删除 1 个旧版
mcsdev dry-run 结束，未改动任何文件
mcsdev （真跑的话，之后会按 restart.command 重启服务器）
```

## `--force`

即使 sha256 相同也重新复制。用途：

- 怀疑判等有问题时排除变量；
- 想让所有条目重新走一遍复制（清单在「已是最新」时也会补记，所以通常不需要 `--force` 做这件事）；
- 目标文件被外部改过但内容恰好相同。

## 什么时候不重启

- 这一轮没有任何条目发生部署（打印「没有需要更新的产物」，并提示可以加 `--force`）；
- 有任何条目失败（打印「N 条失败 —— 不执行重启」）；
- 加了 `--no-restart`；
- `restart.type` 是 `none`（打印「重启策略 none —— 只部署，不重启」）。

## 退出码

| 情况 | 退出码 |
| --- | --- |
| 全部成功（含「没有需要更新的产物」） | 0 |
| 配置解析失败 | 1 |
| 未知 id | 1 |
| 被点名的条目有错误（如没有产物） | 1 |
| 复制失败 | 1 |
| 重启失败（HTTP 非 2xx / 命令非 0 / 等待就绪超时） | 1 |

重启失败也会返回 1，所以 `mcsdev deploy && 下一步` 是安全的。

## 与其他命令的关系

| | 会写盘 | 会重启 | 会 watch |
| --- | --- | --- | --- |
| `config` | 否 | 否 | 否 |
| `ps` | 否 | 否 | 否 |
| `deploy --dry-run` | 否 | 否 | 否 |
| `deploy` | 是 | 是（按策略） | 否 |
| `deploy --no-restart` | 是 | 否 | 否 |
| `dev --once` | 是 | 是（按策略） | 否 |
| `dev --dry-run --once` | 否 | 否 | 否 |
