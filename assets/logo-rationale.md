# mcsdev 标识设计说明

> 交付物：`logo.svg` / `logo-dark.svg` / `logo-mark.svg` / `favicon.svg`
> 全部为手写 SVG，无外部字体、无外部图片、无 JS、无渐变/阴影/滤镜。

---

## 1. 一句话概念

**终端里那个闪烁的方块光标，就是 Minecraft 的那个方块。**

一个 `>` 提示符加一个方块光标，是终端里最日常的一帧画面（`❯ ▊`）；而同一个正方形，又是 Minecraft 世界的最小单位。两个语义共用同一个形状，不需要任何游戏元素，就把「终端」和「方块」焊在一起了。

提示符代表**你**（`mcsdev run` 是唯一要敲的东西），方块代表**被驱动的对象**（测试服 / 实例 / 那个 jar）。它俩永远并排出现，就像 `改代码 → 部署 → 重启 → 看日志` 这个循环里，「你」和「服」永远同时在场。

## 2. 几何构成

所有坐标建立在 **32×32 栅格**上，实际绘制内容锁在中间 **24×24 的正方形**里（四边各留 4 单位 = 12.5% 的安全边距，缩到 24px 时正好是 3px 呼吸）。

| 元素 | 几何定义 | 尺寸（32 栅格） |
|---|---|---|
| 提示符 chevron | `M 5.71 5.71 → 16 16 → 5.71 26.29`，描边 4.85，`linejoin:round`、`linecap:butt` | 绘制高 24（y 4→28），绘制宽 14.43（x 4→18.43） |
| 方块光标 cursor | `<rect x=16.6 y=21.6 w=11.4 h=6.4 rx=1.3>` | 宽 11.4 = 24 方块的 47.5%，高 6.4 = 描边的 1.32 倍 |

三条配比规则，让两个形状读成一个字，而不是两个图标拼在一起：

1. **共用一套栅格。** chevron 的上、下、左三个极值点正好落在 24 方块的边上（y=4 / y=28 / x=4）；cursor 的右边和下边正好落在 24 方块的另外两条边上（x=28 / y=28）。所以整枚图形是「一个正方形里的两个笔画」，而不是两个随手摆的形状。
2. **cursor 压在提示符的笔尖下方。** chevron 的顶点在 x=16，笔画因 miter 外扩到 x≈18.43；cursor 从 x=16.6 起笔——也就是说它从笔尖的**下方**穿过去，形成咬合。两者之间的最小净距是 2.77 单位（斜臂外缘到 cursor 左边）和 3.17 单位（笔尖到 cursor 上边），缩到 24px 仍有 2.0px / 2.4px，不会糊成一块。
3. **chevron 的两臂严格 45°。** 顶点夹角 90°，臂长 14.55。45° 是最「无表情」的斜线角度——它读起来像字体里的 `❯`，而不像播放器里的三角形（后者通常更宽、更钝）。描边两端用 `butt` 平切、顶点用 `round` 微圆：平切让笔画像打出来的字，微圆让尖端不至于扎手。

## 3. 色彩（3 个 hex）

| 色值 | 命名 | 用途 | 实测对比度 |
|---|---|---|---|
| `#0B0E14` | **Ink** 墨 | 浅底上的提示符、方块光标（favicon）、字标 | 对白 19.4:1 |
| `#00C2A8` | **Signal** 信号 | **只给方块光标**用。全套标识里唯一一处彩色，锁排中也只有这一笔 | 对白 2.26:1 / 对墨 8.56:1 |
| `#F5F7F6` | **Paper** 纸 | 深底上的提示符与字标 | 对墨 18.0:1 |

- 强调色只有一笔，且是**实心块**而非细线——`#00C2A8` 在白底上只有 2.26:1，任何细线或文字用它都会塌掉，但一个 11×6 的实心块是能看清的「色块」。
- 深底上它翻到 8.56:1，成为画面里最亮的东西。这是故意的：**光标就是「活着」的那个元素**，服务器在跑，光标就在亮。
- 强调色永不用于正文/小字。全套标识里没有任何文字用 `#00C2A8`。

## 4. 24px 下的取舍

`favicon.svg` **不是** `logo-mark.svg` 的缩放，而是在 24 栅格上重画的：形状位置重算、能砍的细节砍掉、颜色降级。

| 项目 | `logo-mark.svg` 直接缩到 24px | `favicon.svg`（24 栅格直绘） |
|---|---|---|
| 描边 | 3.64px | **3.6px**（比例几乎不变，不需调整） |
| 光标尺寸 | 8.55 × 4.8px | **7.6 × 4.8px**（收短 11%） |
| 光标圆角 | 0.98px → 亚像素，四角糊成灰 | **0.6px**，直角边干净落地 |
| 光标颜色 | `#00C2A8`，白底 2.26:1 | **`#0B0E14`**，19.4:1 |
| 提示符顶点 | x=12.0（16/32 折算） | **x=12.6**，把笔尖与光标的净距拉宽 |
| 绘制总高 | 18.0px | 16.94px |

**被点名的三处「会糊」及处理：**

1. **光标 1.3 单位的圆角**（缩到 24px 只有 0.98px）——亚像素圆角只会让四个角变成灰点，视觉上像渲染错误。→ favicon 降到 0.6px，接近直角。
2. **强调色光标**（`#00C2A8` 对白 2.26:1）——在 24px 下它退化成一坨发白的薄荷色，和旁边的黑色笔画完全不在一个重量级上。→ favicon 整枚降级为单色 `#0B0E14`。这不是偷懒，而是这个尺寸下唯一诚实的做法：**2.26:1 的色块在 8×5 像素时读不出「颜色」，只读得出「脏」。**
3. **光标与斜臂的净距**（缩到 24px 后 2.0px）——这是全图最紧的一处关系。→ favicon 把 chevron 顶点从 12.0 推到 12.6、把光标左边从 12.45 推到 13.4，净距回到 2.85px。

**没有删掉任何形状。** 24px 下两个形状都在，只是把「颜色」和「亚像素圆角」这两样撑不住的东西拿掉了——这正是标识该有的降级方式：丢细节，不丢结构。

**使用边界（重要）：** `logo-mark.svg` 与 `favicon.svg` 是**浅底资产**（墨色笔画）。放到深底上会整个消失（墨对墨）。深底请用 `logo-dark.svg`，或把这两枚的 `stroke` / `fill` 换成 `#F5F7F6`。

## 5. 锁排（lockup）的光学补偿

`logo.svg` 里图形与字标不是「一样大摆一起」，而是做过三处补偿：

- **字标是手绘路径，不是字体。** 几何单线条（monoline）：x-height 46、描边 8.6（= x-height 的 18.7%）、平头端点。`m` 的两个肩是正半圆，`c`/`e` 是 rx19 / ry23 的椭圆，`d` 的碗是正圆（与竖笔相切），`s` 是两个相切椭圆（18 / 11.5）在水平切线处接续，`v` 是两条直线加圆角接点。因为不是字体，所以换任何系统、任何渲染器都长得一样。
- **图形比字标重 17.5%。** 图形描边 8.79，字标描边 7.48。原因很实在：45° 斜线在同样宽度下看起来比横竖线轻约 15%。不补这一刀，图形会明显「发虚」。
- **图形比 x-height 高 9%。** 图形绘制高 43.5，x-height 40，ascender 60.9。对齐 x-height 会像个小写字母，对齐 ascender 又会比正文大一截；取中间值，并把图形的视觉中心对在 x-height 带的中心（上下各溢出 1.75），这样它既不飘高也不下坠。
- 图形到字标的视觉间距 19.5 ≈ 0.49 × x-height。

## 6. 深色版做了什么（不是换底色）

- **墨 → 纸（`#F5F7F6`），不是纯白。** 纯白压在近黑上会「跳」和晕边，纸白更稳。
- **描边整体收 6%**（4.85 → 4.56，7.48 → 7.03）。浅色压在深色上会因为光渗（irradiation）显得更粗，不回收这 6%，深色版会明显比浅色版「胖一圈」。
- **强调色不动。** 它在墨底上是 8.56:1，成为画面唯一的高亮——光标是「在跑」的那一笔。
- 对比度实测：纸对墨 18.0:1（远超 AA/AAA），所以深底上不需要加描边、加阴影或加底衬。

## 7. 放弃的方案（以及为什么）

| 方案 | 为什么讨巧 | 为什么不用 |
|---|---|---|
| 实心圆角方块 + 挖空的 `>` | 最直白的「方块 + 提示符」合体，一眼就懂 | 无论怎么调，它都读成**播放/下一个按钮**。而且 24px 下方块轮廓只是一块黑色正方形，没有任何识别度 |
| 方形描边环 + 左边挖一个 chevron 缺口 | 一个形状同时说「方块」和「提示符」，很省 | 缺口浅了不像 chevron，深了整枚图形就变成**价签 / 书签**。试过 7 组深浅，没有一组逃得掉 |
| 两个互扣的方角括号（方形循环箭头） | 语义最准——它就是这个产品的那条闭环 | 落回**通用的刷新/同步图标**；而且 24px 下两处断口会糊成一圈 |
| 等距立方体 / 体素堆叠 / 像素阶梯箭头 | 最快说出「Minecraft」 | 这正是要避开的：它让专业工具看起来像游戏周边。体素/像素风在 32px 以下必然崩 |
| 圆角方块里的 `m` 字母标（JetBrains 式） | 安全、企业感强、天然可缩放 | 24px 下 `m` 的三根竖笔和两个内白全糊；而且它一个字都没说产品的循环 |
| 大色块 / 字标后面跟一个强调色光标 | 强调色有地方用，还能暗示「实时」 | 大块薄荷绿压在黑色笔画旁边像一块廉价色卡；跟在字标后面又把锁排拉得很长、很贴上去。最后把强调色收成**唯一一笔小光标** |

一句话：凡是「更聪明」的合体方案，都在 24px 或「像不像玩具」这两关上死掉了。所以选了最朴素、但每一根线都能解释的一版。

## 8. 文件清单与技术说明

| 文件 | viewBox | 说明 |
|---|---|---|
| `logo.svg` | `0 0 352.79 72.12` | 主标识，图形 + 字标，浅底用 |
| `logo-dark.svg` | `0 0 352.40 71.93` | 深底用，纸白笔画 + 描边收 6% |
| `logo-mark.svg` | `0 0 32 32` | 纯图形，512×512，头像 / 应用图标（浅底） |
| `favicon.svg` | `0 0 24 24` | 24 栅格直绘的单色简化版 |

- 无 `<image>`、无 `href`、无 `url(http…)`、无 `<script>`、无 `@import`、无外部字体。字标是 `<path>`。
- 无渐变、无 `filter`、无阴影、无多重描边；每枚图形最多两层（一个 `<path>` + 一个 `<rect>`）。
- 每枚文件带 `role="img"` 与 `aria-label="mcsdev"`。
- 不含 Minecraft 官方任何图形元素：没有官方 logo、没有草方块贴图、没有苦力怕脸、没有像素纹理。方块就是一个纯几何正方形。
- 三个 hex 值全库统一：`#0B0E14` / `#00C2A8` / `#F5F7F6`。
